These unmodified Latin WOFF2 subsets of Archivo and IBM Plex Mono were received
from Google Fonts on 3 November 2026 (Asia/Kolkata). `manifest.json` retains the
exact provider URLs, lengths and SHA-256 hashes. The authors' SIL Open Font
License notices are included as `LICENSE-archivo.txt` and `LICENSE-ibmplexmono.txt`.

`miniature.css` uses local CSS family aliases to avoid a late swap with the
terminal's existing external fonts. Preloading and `font-display: optional` keep
the narration stable; a missing font leaves the fallback usable. No binary was
modified. Only the tour loads these assets in the first review unit. The theme
review unit reuses them across the application.

Sources: [Archivo](https://github.com/google/fonts/tree/main/ofl/archivo),
[IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).
