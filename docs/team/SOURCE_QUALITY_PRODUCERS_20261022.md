## Connection and boundaries

`SourceRecord.record(..., source_quality=...)` exports optional camelCase `sourceQuality` without changing legacy fields, status multipliers or numerical readiness. `GET /provenance` projects existing public stores without collecting, modifying the cached source register, creating a visitor ledger or running a migration. Additional retained hourly/operational products are returned in `sourceQualityProducts`, separate from the seven legacy sources used by readiness. The existing Admin Data table and download include both sets. Readiness and status weights are explicitly heuristic, not calibrated accuracy.

The existing inspector now shows supported product meaning, consumer scope, date precision, first receipt, publication, units/statistics/conversions, actual versus requested coverage, parser/projection versions and original evidence. Explicit null normalized clocks never fall back to a misleading legacy timestamp. Malformed optional metadata leaves useful legacy information visible; nonfinite optional JSON is quarantined and public errors contain fixed messages rather than exception paths. Close/Inspect focus behavior and the inline scrolling layout remain intact.

Weather originals from genuine daily connector HTTP responses reuse `current_environment/archive/<sha256>.response`, with immutable receipt metadata and a small cache sidecar. A cache hit changes only its check time. Repeated identical response versions retain first availability; changed versions retain previous-receipt lineage. Reads verify original bytes, request/product binding, parsed-cache agreement and clocks. Metadata or lock write failures preserve readable numerical weather fallbacks. No parsed cache, generated export or filesystem modification time establishes an original receipt.
